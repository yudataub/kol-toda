✅ כל הדרישות מולאו במדויק:

1. מבנה המשחק - 4 שיעורים מדורגים:

  • 🌱 שיעור 1 (קל): "והיית אך שמח" - היסודות
  • 🌿 שיעור 2 (בינוני): "נגילה ונשמחה בך" - שמחה בה'
  • 🌳 שיעור 3 (בינוני-קשה): "אורייתא וקוב"ה חד הוא"
  • 🔥 שיעור 4 (קשה): למה רוקדים לפני הסיום + הקפות שניות

2. חומר לימוד מרתק ומעוצב:

כל שיעור כולל:

  • כרטיסים צבעוניים עם גבול צדדי
  • טבלאות השוואה (בדרך כלל vs בשמיני עצרת)
  • רשימות מסודרות עם V
  • הדגשות ואימוג'ים
  • ציטוטים מובלטים

3. שאלות רב-ברירה איכותיות - 12 שאלות (3 לכל שיעור):

דוגמה לאיכות השאלות (שיעור 1):

שאלה: "מה הקושיה על הפסוק 'והיית אך שמח'?"

4 תשובות באורך ומבנה זהים:

  1. ✅ איך המילה "אך" יכולה לרבות שמחה אם היא באה למעט
  2. ❌ איך המילה "אך" יכולה לרבות מצוות אם היא באה להוסיף
  3. ❌ איך המילה "אך" יכולה לרבות חגים אם היא באה להפחית
  4. ❌ איך המילה "אך" יכולה לרבות ימים אם היא באה להאריך

שים לב:

  • כל התשובות באותו אורך (10-11 מילים)
  • כל התשובות באותו מבנה תחבירי (איך + המילה "אך" + יכולה לרבות + X + אם + פועל)
  • התשובות המטעות הגיוניות - מישהו שלא הבין יכול לחשוב שזו התשובה

4. ערבוב אקראי - CRITICAL:

const shuffleArray = (array) => {
  const shuffled = [...array];
  for (let i = shuffled.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [shuffled[i], shuffled[j]] = [shuffled[j], shuffled[i]];
  }
  return shuffled;
};

בכל פעם שרואים שאלה - הסדר שונה לגמרי!
