🎯 חידונים כיתתיים

חידוני אתגר לכל הכיתה: המורה מדפדף, כל תלמיד עונה במחשב שלו, ויחד רואים מי ענה, את התוצאות באחוזים, את ההסבר ואת מוסר ההשכל – בלי לחשוף מי ענה מה.

איך משתמשים בכיתה?
  1. במחשבי התלמידים מותקנת התוכנה "הקול החמישי – כיתה" (גרסה 28 ומעלה).
  2. בלוח המורה (kol-kiosk-class.web.app) מדביקים את הקישור של החידון ולוחצים "הצמד לכולם".
  3. מדפדפים בחצים. בחידון עם דף לימוד: לימוד קצר ← שאלה עם שעון של דקה ← תוצאות באחוזים ← הסבר ומוסר השכל. במקרן: "⛶ מסך מלא".
  4. תלמיד בלי התוכנה (טאבלט, מחשב בבית): פותח את קישור החידון ומוסיף בסופו ?class= וקוד הכיתה. הדפים מתהפכים אצלו יחד עם המורה, והוא עונה מהדפדפן.
  5. בסוף: אחוז ההצלחה של הכיתה, פרסים, וכל תלמיד רואה כמה צדק.
