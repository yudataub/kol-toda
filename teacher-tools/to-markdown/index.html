ממיר ל-Markdown

רוצים לתת ל-Claude, ל-ChatGPT או ל-NotebookLM דף עבודה, מבחן סרוק או מצגת? התוכנה הופכת את הקובץ לטקסט נקי בעברית, כדי שהבינה המלאכותית תקרא אותו נכון ותחסכו מקום בשיחה. חינם.

⬇ הורדת התוכנה (ZIP) 📖 איך מתקינים
ל-Windows 10 ו-11 · ההמרה נעשית במחשב, והקבצים לא נשלחים לשום מקום · ← לארגז הכלים למורה

מה התוכנה עושה

📄 כל סוגי הקבציםPDF (גם סרוק), Word, PowerPoint ו-Excel (גם הישנים), RTF, ODT, תמונות, HTML, EPUB ו-ZIP.
🔤 עברית תקינהגם מ-PDF שבו הטקסט יוצא הפוך בכלים אחרים.
🔍 קריאת סריקותדף סרוק או צילום של דף נקראים בזיהוי טקסט (OCR).
🔒 פרטיהכול קורה במחשב שלכם. הקבצים לא עולים לאינטרנט.

התקנה

  1. מורידים את קובץ ה-ZIP, לוחצים עליו בלחצן הימני ← "חלץ הכול".
  2. בתיקייה שנפתחה לוחצים פעמיים על INSTALL.bat.
  3. אם מופיע חלון כחול "Windows protected your PC": לוחצים "More info" ← "Run anyway".
  4. אם Windows שואל אם לאשר שינויים במחשב, לוחצים "כן". זה יקרה עד פעמיים.
  5. מחכים להודעה שההתקנה הסתיימה. זה לוקח 10–15 דקות. לא סוגרים את החלון השחור.
ההתקנה צריכה חיבור לאינטרנט וכ-2GB פנויים. היא מתקינה גם Python, Tesseract (לקריאת סריקות) ו-LibreOffice (לקבצי Word ו-PowerPoint ישנים). כולם חינמיים.

שימוש

  1. פותחים את "ממיר ל-Markdown" משולחן העבודה. נפתח דף בדפדפן.
  2. גוררים אליו קובץ, כמה קבצים או תיקייה שלמה.
  3. לוחצים "העתק" ומדביקים בשיחה, או מעלים את קובץ ה-md שנשמר.
דרך מהירה: לחיצה ימנית על קובץ ← "שלח אל" ← "המר ל-Markdown". ב-Windows 11 לוחצים קודם על "הצג אפשרויות נוספות".

שאלות ותקלות

ההתקנה נעצרה עם הודעה על Python או על ספריות

ההתקנה מורידה את Python מ-github.com ואת הספריות מ-pypi.org. אם יש סינון אינטרנט, ייתכן שהוא חוסם אותם. אפשר לבקש מהסינון לפתוח את שני האתרים ולהריץ שוב את INSTALL.bat.

התמונות שבקובץ לא מופיעות בטקסט

נכון, התוכנה מעבירה רק את הטקסט. אם חשוב מה רואים בעמוד (תרשים, ציור), מעלים לבינה המלאכותית גם את הקובץ המקורי.

יש טעויות בטקסט של דף סרוק

טקסט סרוק נקרא בזיהוי אוטומטי, ועלולות להיות בו טעויות. סריקה חדה וישרה נותנת תוצאה טובה יותר.

איך מסירים?

מוחקים את התיקייה %LOCALAPPDATA%\ToMarkdown ואת קיצור הדרך משולחן העבודה. את Tesseract ו-LibreOffice מסירים מההגדרות של Windows, בחלק של האפליקציות.
